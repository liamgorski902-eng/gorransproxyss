        About Gorransproxy

        Gorransproxy is a small, dependency-free web proxy with a Polish soul and a hard-working beaver mascot. It was built to show what a responsible proxy looks like.

        Proxy mode only talks to a short list of approved websites, requires an access code, limits how fast anyone can browse, and refuses to reach private networks.

        • Approved sites onlyEvery destination is checked against an allowlist.
        • Scripts removedPages are cleaned and sandboxed before you see them.
        • Private and rate-limitedAccess codes and request limits keep abuse out.

        Help

        Why can't I open a site in Proxy mode?

        Proxy mode only opens sites on the server's allowlist, shown under the address bar. The owner can add more with the ALLOWED_HOSTS setting.

        Why do pages look plain?

        Scripts are removed for safety, so interactive features, logins and videos do not work. Text, images and basic styling do.

        What is Unblocker mode?

        A convenient search box and shortcut grid. It opens Google and popular sites directly in a new tab; it does not bypass any network restrictions.

        Can I use YouTube, TikTok or Snapchat in Proxy mode?

        No. Those services need scripts, logins and streaming, which this proxy intentionally blocks. Use the shortcuts to open them directly.

        I forgot my access code.

        Ask whoever runs this Gorransproxy server. Codes are set with the ACCESS_CODES setting.
